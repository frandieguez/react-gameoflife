## Direction contract

**THESIS:** The grid always was a punch card waiting for someone to program it — refusing the two worlds already tried (neon terminal, culture plate) for the literal historical artifact that already encodes a binary grid as physical holes.

**OWN-WORLD:** Warm kraft/manila card stock (never pure white), one clipped corner (the Hollerith registration cut), faint printed column-guide ticks across the top margin, round sprocket/void holes running down both side margins. A live cell is a rectangular die-cut hole with a warm amber reader-lamp light glowing through it from below the card; a dead position stays a faint printed registration mark, never simply blank. Generation/speed readouts print as a tear-off ticket stub (dashed rule, sepia ink, Space Mono) at the card's foot. Below the card, a dark machine chassis (the reader deck) holds the controls — paper above, machine below.

**STORY:** A visitor opens the link and finds a punched card already loaded into a reader; pressing the deck's control feeds it through, and an amber scan-bar sweeps the card once per pass as the reader interprets each row, holes blinking into existence and vanishing generation over generation.

**FIRST VIEWPORT:** The card slides up into the reader slot with a decisive mechanical snap (not a bounce), then a single bright scan-bar sweeps top-to-bottom once, confirming the seeded holes as it passes. While running, the same scan-bar loops continuously, slower, as the read-in-progress cue.

**FORM:** Impeccable's-pick candidate (own top-ranked grounded direction, "Punch card / Jacquard loom pattern card"), originally offered as the declined-roll alternative to assigned seed `c6986f96`; the user pinned this direction explicitly, which outranks the roll by contract.

**FINISH:** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
